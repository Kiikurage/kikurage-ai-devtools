# compare-imgs

同梱のバイナリ `bin/compare_imgs` で、画像を 1 枚の一覧にする。

このスキルのベースディレクトリ（スキルを読み込んだときに示される「Base directory for this skill」）を `D` として、`$D/bin/compare_imgs` を呼ぶ。

```sh
"$D/bin/compare_imgs" [-w 幅px] [-h 高さpx] -o 出力 -i 画像1 [ラベル1] -i 画像2 [ラベル2] ...
```

- `-w` `-h`：一覧の最大の大きさ（既定 2400x1600）。片方だけなら、もう片方は 2:3 の比で決まる
- `-o`：出力のパス（`.png` か `.jpg`。見るだけなら `.jpg` が軽い）
- `-i`：画像のパスと、任意のラベル。次の引数が `-` で始まらなければラベルになる。空白を含むラベルは引用符で囲む。
  拡張子の無いパスには `.png` を補う
- `--gap`（余白、既定 8）、`--bg`（white / black / #rrggbb）、`--font`（ラベルのフォント。既定はヒラギノ角ゴシック W6）
- ヘルプは `--help`（`-h` は高さ）

並べ方は自動。1 行から n 行までの分け方を試して、指定の大きさの中で画像がいちばん大きく収まるものを選ぶ。
各行は高さを揃えて横幅いっぱいに並べ、渡した順は崩さない。縦長と横長が混ざってもよい。

## 結果の読み方

画像の左上に通し番号とラベル、左下にパスが入る。標準出力にも、1 枚ごとに 1 行で番号・位置・パス・ラベルが出る。

```
/path/to/out.jpg  2399x1336
1	1行目 1列目	x=0 y=0 452x678	runs/a/s1.png	#167 採用
2	1行目 2列目	x=460 y=0 452x678	runs/b/s2.png	#167 見送り
```

一覧の画像を Read で見て判断するときは、画像の中の文字に頼らず、この標準出力で「何番がどの画像か」を突き合わせる。

## 使うときの決まり

- 出力は見るため・見せるためだけのものなので、スクラッチパッドに出す。作業ディレクトリには置かない
- ユーザーに見せるときは、並べた画像のそれぞれの出どころ（元の画像を開ける URL、無ければパス）を、番号と合わせて書き添える
- ラベルには、見比べる観点が分かる短い言葉（カットの番号、採用／見送り、変えた条件など）を入れる

## 作り直すとき

ソースは `src/`（Go）。直したら、スキルに同梱するバイナリを作り直す。

```sh
cd skills/compare-imgs/src && go build -o ../bin/compare_imgs .   # リポジトリのルートから
```
