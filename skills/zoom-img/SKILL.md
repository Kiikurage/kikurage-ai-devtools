# zoom-img

同梱のバイナリ `bin/zoom_img` で、画像の一部を目盛り付きで拡大する。

このスキルのベースディレクトリ（スキルを読み込んだときに示される「Base directory for this skill」）を `D` として、`$D/bin/zoom_img` を呼ぶ。

```sh
"$D/bin/zoom_img" -i 画像 [--at X,Y] [--win px] [--size px] [--mark X,Y ...] [--px X,Y ...] [--smooth] -o 出力
```

- `-i`：元の画像。拡張子の無いパスには `.png` を補う
- `-o`：出力のパス（`.png` か `.jpg`）
- `--at`：切り出す窓の中心（元画像の座標）。省くと画像の中心
- `--win`：切り出す窓の一辺 px（既定 400）。窓の大きさで目盛りの刻みが変わる（250 より大きいと 50、60 より大きいと 10、それ以下は 5）
- `--size`：出力の一辺 px（既定 800）
- `--mark`：赤丸で示す点。何度でも渡せる（前の段階で当たりを付けた点を確かめる用）
- `--px`：RGB を読んで標準出力に出す点。何度でも渡せる。図にも黄色の小さな輪を付ける
- `--smooth`：補間して拡大する。既定は最近傍で、画素をそのまま大きく見せる（補間すると線や縁がにじみ、太さや色を読み違える）
- ヘルプは `--help`

## 寄り方

窓を狭めながら繰り返す。

1. 全体の当たり：`--win 400` 前後で、見たい物のあたりを見る
2. 寄る：目盛りで座標を読み、`--at` をそこへ動かして `--win 120`、さらに `--win 40` と狭める
3. 数値で確かめる：色・線の太さ・縁の層は `--px` で横一列や縦一列の点を読む（例：縁をまたいで 3px おきに 5 点）

窓が狭いほど 1 画素が大きく写る。線の太さや縁の層（線 → 白い抜け → 塗り）は、1 画素が 5〜10px になるまで寄ってから言う。

## 結果の読み方

目盛りの数字は元画像の座標。太線は刻みの 5 倍ごと。線の間隔が十分あるときは細い線にも数字が付く。
標準出力に、窓の範囲・倍率・刻みと、`--px` の点の RGB が出る。

```
/path/to/zoom.png  800x800
窓 x=70..150 y=70..150（80px 四方、10.00 倍、目盛り 10px 刻み、太線 50px ごと）
px 82,110	RGB(60, 44, 51)	α=255
px 85,110	RGB(243, 230, 234)	α=255
```

色は図の見た目ではなく、この数値で言う。

## 使うときの決まり

- 出力は見るためだけのものなので、スクラッチパッドに出す。作業ディレクトリには置かない
- 参考画像を真似るときは、真似る要素ごとに寄って観察した結果（形・縁・塗り・色・位置関係）を書いてから作る。出来たものは、参考の同じ部分と同じ窓の大きさで寄って並べて比べる（並べるのは compare-imgs）
- 指摘を受けたら、合わせて直す前に、その点を寄って確かめる

## 作り直すとき

ソースは `src/`（Go）。直したら、リポジトリのルートで `scripts/build.sh` を実行し、同梱するバイナリを全アーキテクチャ分作り直す。
`bin/zoom_img` は OS とアーキテクチャを見て `bin/zoom_img-<os>-<arch>` を呼ぶラッパー。
